# FiLM-OSG

![python](https://img.shields.io/badge/python-3.11-blue)
![pytorch](https://img.shields.io/badge/pytorch-2.0.1-orange)

Code for the numerical experiments in the FiLM-OSG manuscript. FiLM-OSG
learns PDE evolution over variable time lags by applying feature-wise
modulation inside an operator backbone. The main experiments compare
FiLM-OSG-FNO with direct-lag OSG-FNO on Burgers, advection--diffusion, and
Navier--Stokes equations.

## Installation

```bash
conda create -n film_osg_clean python=3.11 -y
conda activate film_osg_clean
python -m pip install torch==2.0.1+cu117 --index-url https://download.pytorch.org/whl/cu117
python -m pip install -r requirements.txt
```

Use a PyTorch build compatible with the local CUDA driver. The tested package
versions are listed in [`docs/environment.md`](docs/environment.md).

## Data

Place the data files in `data/` or pass another directory through `--data-dir`.

| Experiment | Training data | Test data |
| --- | --- | --- |
| Burgers | `BurgersOSG_train.mat` | `BurgersOSG_test.mat` |
| Burgers with steep gradients | `burgers_sharp/BurgersSharpOSG_train.mat` | `burgers_sharp/BurgersSharpOSG_test.mat` |
| Advection--diffusion | `train_data.mat` | `test_data.mat` |
| Navier--Stokes | `VorticityOSG_train.mat` | `VorticityOSG_test.mat` |

The Burgers and advection--diffusion generators are in
`scripts/data_generation/`. Navier--Stokes uses the data format of the public
DUE benchmark. Data formats and generation details are recorded in
[`data/README.md`](data/README.md); large `.mat` files are not tracked by git.

The additional Burgers dataset with steep gradients is generated by

```bash
python scripts/data_generation/generate_burgers_sharp_osg.py --out-dir data/burgers_sharp
python scripts/check_burgers_sharp_data.py --data-dir data/burgers_sharp
```

## Training and evaluation

The model names `fno` and `fno_film` denote direct-lag OSG-FNO and
FiLM-OSG-FNO, respectively. A matched single-seed Burgers run is

```bash
python train/run_burgers_fno.py --model fno --seed 0 --tag burgers_main --dataset original --data-dir data --epochs 1000
python train/run_burgers_fno.py --model fno_film --seed 0 --tag burgers_main --dataset original --data-dir data --epochs 1000
python eval/eval_burgers_fno.py --models fno,fno_film --seeds 0 --tag burgers_main --dataset original --data-dir data --save-dir eval_outputs_burgers
```

The five-seed runs can be distributed across several GPUs:

```bash
python scripts/launch_burgers_fno.py --gpus 0,1 --tag burgers_main --dataset original --data-dir data
```

The corresponding entry points for the other two equations are

```text
train/run_convdiff_fno.py    eval/eval_convdiff_fno.py
train/train_ns_one.py        eval/eval_ns_fno.py
```

The reported summaries use seeds `0,1,2,3,4`. Commands for all three main
experiments, the PDEBench-derived checks, additional diagnostics, figures, and
profiling are collected in [`docs/reproduction.md`](docs/reproduction.md).

## Checks

After installing the environment, the command-line options can be inspected
without loading data or using a GPU:

```bash
python train/run_burgers_fno.py --help
python train/run_convdiff_fno.py --help
python scripts/launch_convdiff_fno.py --help
python train/train_ns_one.py --help
python scripts/launch_ns_fno.py --help
```

The CPU smoke test covers the main FNO, FiLM, projection, high-frequency loss,
and global--local paths:

```bash
python scripts/smoke_new_features.py --device cpu
```
