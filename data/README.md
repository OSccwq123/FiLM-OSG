# Data Directory

Place benchmark `.mat` files in this directory. Active scripts default to this
path and also accept `--data-dir` for alternate locations.

Two data-generation scripts are included:

- `Burgers.m`: generates `BurgersOSG_train.mat` and `BurgersOSG_test.mat`.
- `convection_diffusion.m`: generates `train_data.mat` and `test_data.mat` for
  the 2D advection--diffusion benchmark.

The Navier--Stokes files are DUE benchmark data used by our group and are not
generated by scripts in this repository.

The repository `.gitignore` keeps `*.mat` files out of normal git commits.
Some files exceed GitHub's regular 100 MB file limit. If distributing data
through GitHub, use Git LFS or a GitHub Release asset after confirming that the
dataset redistribution permission is clear.

The Navier--Stokes files are derived from the DUE benchmark data used by our
group. Keep the DUE attribution in `NOTICE` and `docs/third_party_attribution.md`
when redistributing these files.

## Regenerating Scripted Data

Run these commands from MATLAB with this directory as the working directory, or
open the scripts directly:

```matlab
Burgers
convection_diffusion
```

Both scripts write their `.mat` outputs into this directory. They may also write
small diagnostic `.png` files, which are ignored by git. For headless/server
runs, set `make_plots = false` near the top of each script before running.

Expected variable names:

- Training files include `coordinates`, `dt`, and `trajectories`.
- Test files include `dt` and `trajectories`; Burgers test also includes
  `coordinates`.

The stored checksums above document the local `.mat` files currently used for
smoke tests. If the generation scripts are edited or rerun under a different
MATLAB version, regenerate the checksums before publishing data artifacts.
