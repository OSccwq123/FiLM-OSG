# Third-Party License Texts and Notices

This directory records third-party license texts, notices, and release-review
notes for code provenance in the FiLM-OSG reproducibility repository.

The final top-level repository license has not yet been selected. Before public
release, confirm the top-level release terms with the authors and advisor.

Current files:

- `DUE-LGPL-2.1.txt`: GNU Lesser General Public License v2.1 text for files
  adapted from AI4Equations/DUE, whose upstream repository is marked as
  LGPL-2.1 licensed.
- `NEURALOPERATOR-MIT.txt`: MIT license notice for the neuraloperator FNO
  reference, whose upstream repository is marked as MIT licensed.
- `MAMBA-APACHE-2.0.txt`: Apache-2.0 license text for the optional
  `mamba_ssm` dependency from state-spaces/mamba.
- `ARCHITECTURE_REFERENCES.md`: release-review notes for U-NO-style,
  Transolver-style, and MambaNO-style architecture references used as
  paper/project inspirations. These implementations are local OSG-adapted
  variants and the upstream codebases are not vendored here.
